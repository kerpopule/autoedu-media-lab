# AutoEDU.ai Media Lab

Standalone controller extracted from the already-public VibeXStudio source revision
`0b8cd24e848ea5da89148fb74cbc2399f394186e`. Existing Apache-2.0 license and
third-party attribution are retained. This export contains no private runtime state
or model weights. Models and external runtimes keep their own licenses.

The public project home is https://autoedu.ai/MediaLab. VibeXStudio is now the
Meadows-based space-design studio at https://vibexstudio.com.

Compatibility is intentional: CLI command, data roots, service identifiers,
access codes, pairing QR schema, `/api` routes and `vibexStudio` capability keys
are unchanged. Existing native clients are legacy compatible clients, not required
parts of this independent product. No new desktop binaries are claimed.
